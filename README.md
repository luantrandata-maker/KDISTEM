# Hệ thống Quản trị STEM

Giai đoạn 1–2: nền tảng + vận hành trường.

1. Migration `001` đã được áp dụng lên project Supabase `stem-management-system`.
2. Biến môi trường trong `.env` đã điền sẵn. Người đăng ký đầu tiên tự trở thành quản trị Trường THCS Phố Hiến (chỉ dùng cho giai đoạn demo).
3. `npm install && npm run dev`
